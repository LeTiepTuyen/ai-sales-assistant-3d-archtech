# 00 — Start Here

This project is a demo AI Sales Assistant for 3D Archtech. The goal is to quickly build a local-first MVP that can:

1. Answer sales questions from internal company materials.
2. Explain technical concepts in business-friendly language.
3. Generate proposal drafts from old proposal templates and client inputs.
4. Let an admin add/re-ingest data sources.
5. Export proposal output as DOCX and PDF/print-friendly view.

## First Codex Task

After copying source files into `data/source-pdfs/`, run:

```text
@prompts/01-generate-project-documents.prompt.md
```

Codex must create detailed Business, Product, Technical, Data/RAG, UI/UX, Demo, Deployment, Tasks, Progress, and Decisions documents before coding.
